How It Works

1
Student receives suspicious message on WhatsApp
↓
2
Forwards it to the TruthLens WhatsApp bot number
↓
3
TruthLens AI analyzes the message instantly
↓
4
Receives detailed credibility report in the chat
⚙️

Setup Guide

1
Create a free Twilio account

Visit twilio.com and sign up for a free account.

2
Activate WhatsApp Sandbox

In Twilio Console → Messaging → Try it out → WhatsApp. Send the join code from your phone.

3
Copy credentials to .env

Copy your ACCOUNT_SID and AUTH_TOKEN into your .env file.

4
Install & run ngrok ngrok http 5000

Copy the https://xxxx.ngrok.io URL it gives you.

5
Set Webhook URL in Twilio

In Twilio Console → WhatsApp Sandbox → "When a message comes in", paste:

https://your-ngrok-url.ngrok.io/webhook
6
Test it!

Send any message to the Twilio WhatsApp sandbox number and watch TruthLens respond.
